# Heleme public pages

Public privacy policy and support pages for Heleme, provided by Fenrir Chengdu Inc.

This repository contains only public website content. It does not contain app source, water records, credentials, signing files, screenshots or test artifacts.

Deploy from the `main` branch root using Settings → Pages → Deploy from a branch. Public files: `privacy.html`, `support.html`, `index.html`, `style.css`.

Support: support@fenrir-inc.com.cn

## Content update: November 1, 2026

The Chinese and English pages describe version 2.0 smart reminders, saved single-period optimization, fixed-mode inactivity and management, entered drinking times, recorded-day averages, goal history and local backup boundaries. Earlier installed app versions may differ.

Before updating, check these descriptions against the implementation and render both pages at phone and desktop widths. After merging, verify the Pages deployment and the actual public response; a merged commit alone does not confirm publication.
